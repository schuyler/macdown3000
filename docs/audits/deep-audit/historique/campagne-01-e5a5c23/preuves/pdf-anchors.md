# PDF anchors — correction de correspondance DOM/PDF

2026-10-07. MPPDFAnchorInjector.h/m et MPPDFAnchorInjectorTests.m intégralement lus et analysés. Versions corrigées relues ; tous les tests existants et ajouts examinés. MPDocument.m : uniquement constante kMPAnchorModelJS et receiver readAnchorLinks lus/édités/relus dans ce souslot ; lecture globale du fichier appartient au coordinateur. Validation demeure false.

Défaut confirmé : le modèle DOM capture tous les liens internes, y compris après un titre, tandis que l’injecteur supposait que leurs occurrences apparaissaient avant les headings. Un texte identique présent dans un paragraphe décalait également source/destination. Le pipeline runtime fournit maintenant occurrenceIndex (base zéro) et occurrenceCount du même texte dans tout le corps visible, pour liens et titres ; les textes de script/style/noscript et invisibles sont ignorés, inline span conserve les mots complets, fragments URL décodés. L’injecteur sélectionne les occurrences explicites seulement si cardinalité PDF == DOM ; différence de contenu imprimé entraîne exclusion du seul lien ambigu. Les anciens constructors restent pour contrat TOC-only documenté, utilisé uniquement par fixtures historiques ; runtime ne les utilise plus. Capture géométrique PDFSelection immuable préservée, source/destination sur pages canoniques préservées.

Quatre nouveaux tests : lien inline après heading vers heading antérieur ; deux liens partageant même texte avec deux paragraphes homonymes et heading de même taille ; mismatch cardinalité source/destination n’affectant pas les autres liens ; modèle réel WebView avec corps répété, span inline, texte caché et fragment encodé. Tests PDF utilisent NSPrintOperation réel comme fixtures existantes.

Checks locaux hors Xcode : node --check du JS ; modèle extrait des literals Objective-C exécuté sur fixture DOM simulée, assertions exactes [link1 index1/count5, link2 index4/count5, heading index2/count5], succès. Ceci ne remplace pas le test WebView/PDF centralisé. Aucun build lancé par cet agent.
