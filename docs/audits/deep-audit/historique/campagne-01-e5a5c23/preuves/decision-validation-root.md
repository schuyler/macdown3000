# Décisions finales root — code, ressources et configuration

Ces décisions s’appuient sur les lectures complètes historiques et finales correspondant aux SHA de l’inventaire, l’analyse des symboles et consommateurs consignée dans root.md, ui-preferences.md, reprise-root.md et reprise-resources.md, et les contrôles finaux R14/R15. La liste a été examinée comme unités de contrats ; aucune case n’est déduite du seul SHA ou d’un build. Les décisions UI/Document, build/CLI et rendu/QuickLook ont leurs notes séparées.

- Catégories Foundation/DOM, utilitaires et vues : bornes Unicode/sélections, types/encodage, erreurs, ownership, scope URL et watchers/générations réexaminés ; tests natifs consommateurs de la suite1427/0 et UI4/4, sans défaut confirmé restant. Les watchers sont exercés sur le vrai système de fichiers. Les interfaces déclaratives concordent avec les implémentations et les appelants.
- Contrôleurs application, toolbar et accessoires : actions, sélection, export différé et ouvertures avec leurs consommateurs réconciliés ; fixes atomiques, copies d’aide isolées et erreurs testées. Les paramètres URL scheme line/column sont explicitement non implémentés (FIXME historique), sans exigence publique retrouvée de placement du curseur : limite fonctionnelle documentée, pas correction spéculative. Ils ne sont pas annoncés supportés.
- XIB, locales et catalogues d’assets : chaque entrée et ID lu, bindings/selectors/format placeholders/règles pluriels confrontés aux consommateurs ; corrections finales relues. NIB réels testés, plutil/XML/JSON et compilateur de ressources verts, titres/pluriels affectés consommés dans les deux bundles finaux. Les traductions sont validées comme contrats techniques ; aucune expertise linguistique native universelle revendiquée.
- Styles, thèmes, templates et adaptateurs JavaScript : toutes règles finales lues ; vrais parsers de thèmes, vraie génération Sass/Primer, CSS de rendu/print et PDFKit ; Mermaid8types et Graphviz6moteurs au vrai performAfterRender, MathJaxOFF/ON. Les scripts fournisseurs restent explicitement exclus ; les adaptateurs internes sont couverts. Les maps cachées sont décodées et leurs consommateurs actifs sont identifiés ; pas d’exécutable caché démontré ni suppression legacy injustifiée.
- Configuration build, dépendances et workspace : entrées et chemins lus, lockfiles/intégration cohérents avec les builds propres universels et les suites réelles ; versions identiques app/extension. Le workspace périmé MarkPad a été corrigé et relu intégralement, self: est consommé par les deux builds. Les déclarations ne certifient aucune publication/notarisation distante.

Pour les chemins suivants, les contrôles nécessaires au contrat source dans le périmètre local sont satisfaits et aucune hypothèse déterminante ouverte ne reste. Les limites OS, providers tiers et distribution restent dans les preuves ; une absence de garantie universelle n’est pas convertie en finding. Décision : Validé.
