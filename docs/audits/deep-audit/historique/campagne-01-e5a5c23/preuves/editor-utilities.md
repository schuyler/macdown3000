## Flux et seconde passe

Édition → Document actions → Autocomplete → insertion NSTextView/undo/range ; marqueurs entiers et sélection bornée vérifiés statiquement sur lignes vides, multi-digit et curseur dans marqueur. Document navigation/resources → URL scope/HTML resolver → watcher local → callbacks/save atomique : tokens empêchent effets des générations supprimées et ownership source/block évite cycle. Rendu → JS extraction/YAML → JSON/frontmatter HTML : Unicode bytes, exceptions, aliases et ownership MRC relus. Thème utilisateur → C stylesheet → styles Cocoa → asynchronous parser → view active : limites tableaux, override ordering, générations et scroll independent réexaminés. Build→greg bootstrap→grammar→concat : bootstrap réel conservé, entrée generator lue et corrigée, aucun fichier legacy supprimé. Release/staple→website : données shell séparées du code, smoke unifié, aucune action distante ni signature/notarisation exécutée.

## Code caché et exclusions

`MPGetDataMap` consomme deux archives bundled, pas un chemin fourni par document. `data.map` contient PNG1500×1500 (2 892 399 octets) associé à `MoskyかわいいよMosky`, inséré historiquement via Autocomplete. `treats.map` contient MMDD0214/0819/0314 : Markdown Valentine/Birthday/White Valentine avec CSS et fences Python (non exécutés). MainController déclenche cet easter egg selon activation/date/auteur. Effet historique caché documenté ; non qualifié malware et non supprimé comme legacy. Entrée `.DS_Store` est donnée binaire auxiliaire non choisie par MMDD, aucune suppression arbitraire. Sources maps hors code principal mais archives décodées intégralement et contenu textuel lu.

Fichiers `pmh_parser.c`, `pmh_parser_core.c` exclus comme outputs Makefile, inputs head/grammar/foot et generator tous lus. `greg/greg.c` inclus malgré commentaire generated car bootstrap compilé réel. `greg/greg`, `.o` exclus outputs binaires build. Hoedown patch autre propriétaire root. Tests/docs hors inventaire principal, tests nécessaires complétés.
