Le callback produisait classe `language-*` uniquement sur CODE. Prism tomorrow colore CODE #ccc, mais son fond sombre #2d2d2d exige la classe sur PRE. Le stylesheet GitHub2 laisse alors son fond clair. Dans l'app, Prism.highlightElement propage la classe au parent PRE ; cette correction dynamique masquait l'omission du markup. Désactiver scripts/CSP est une protection valide à conserver.
