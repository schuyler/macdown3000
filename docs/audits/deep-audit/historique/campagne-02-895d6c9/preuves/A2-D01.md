# A2-D01 — sélection tronquée lors de l'indentation de lignes vides

Campagne 02, défaut P2 confirmé sur la base e5a5c23. Le menu Indent et Tab avec sélection passent par MPDocument.indent puis NSTextView.indentSelectedLinesWithPadding. Le texte produit ajoutait la marge à toutes les lignes intérieures, mais totalShift ne comptait que les lignes non vides. La fin de sélection était donc raccourcie d'une marge par ligne vide. Une édition ultérieure pouvait porter sur une partie différente de celle choisie.

Reproduction réelle AppKit, avant correction : sélectionner entièrement `a\n\nb`, indenter avec quatre espaces. Le texte est correct mais selectedRange vaut `{4,8}` et exclut le `b` final. L'invariant attendu est `{4,12}`, couvrant tous les caractères sélectionnés et les marges intérieures.

Correction : calculer séparément les deux positions originales et leur déplacement selon chaque marge effectivement ajoutée. Le composant vide terminal n'est pas indenté, conformément au comportement existant. Les marges et caractères produits sont conservés.

Régression : `python3 MacDownTests/BuildTools/indent_selection_tests.py` compile les fichiers de production complets, YAML avec son mode MRC, LibYAML et M13OrderedDictionary installés, dans un répertoire temporaire. Aucun stub de mutation/NSString ni préférence utilisateur. Le vrai NSTextView reçoit indentation puis désindentation ; six scénarios contrôlent contenu et sélection : ligne vide intérieure, tabulations et newline final, lignes vides initiales, sélection partielle, caret sur ligne vide, document vide. Compilation d'abord corrigée pour respecter les headers/MRC du projet, sans modification des dépendances de production.

Rouge métier : exit 1, sélection `{4,8}`. Vert initial : `{4,12}`. Vert final : six allers-retours exacts, exit 0. Catégorie finale relue entièrement après correction, méthodes voisines de marqueurs/titres/désindentation confrontées au calcul de positions. Gates Xcode/AppKit dans l'application complète encore à exécuter ; ce test ne certifie pas toute l'autocomplétion ni l'undo système.
