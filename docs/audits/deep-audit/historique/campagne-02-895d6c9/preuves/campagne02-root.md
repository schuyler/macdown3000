# Campagne 02 — document et utilitaires

Lecture intégrale, analyse et validation manuelle des 47 chemins du lot root-document terminées :45 sources initiales et2 archives actives décodées. Les décisions par fichier sont dans campagne02-root.json ; preuves actuelles reliées aux versions effectivement relues et aux consommateurs.

Lecture initiale MPDocument.m sans trou : plages 1–360, 361–1000, 1001–1650, 1651–2300, 2301–2950, 2951–3600, 3601–4250, 4251–4900, 4901–5367. Toutes déclarations, constantes JavaScript, catégories et méthodes considérées. Les 44 autres chemins lus intégralement par groupes de fichiers complets ; catégorie Autocomplete relue entièrement après A2-D01.

Parcours examinés : initialisation et différé nib, setup highlighter/renderer et observateurs KVO/notifications, chargement UTF8 et normalisation CRLF, sauvegardes locales/directes et restart watchers, restauration selection/scroll, fenêtres/onglets et sync sidebar, autocomplétion/menu/commandes et textStorage, flags parser/render, DOM replacement versus navigation complète, MathJax initial et replacement avec générations, ressources/cache busting, comptages DOM/sélection, propriétaires de scroll et géométrie/alignment borné, zoom partagé/font/preview, completion print NSInvocation, HTML/PDF différés et publication atomique, identités natives du deuxième PDF et restore CSSOM/media/DOM, checkboxes token/source offset, navigation locale/scoping/symlinks/exécutables, reload externe/prompts/générations, fermeture/cleanup.

MainController : updater déféré et désactivé XCTest, URL scheme, copies Help/Images et traitements des maps, migrations/copies/pruning styles, files/folders/stdin pending, workspace avant nib et première ouverture. Les préférences productrices appartiennent au lot UI et le CLI au lot build : leur analyse commune a confirmé A2-B03. Le commit 431c456 migre les producteurs et le consommateur vers une seule queue privée verrouillée ; les anciennes préférences sont converties avant effacement, et leurs anciennes API supprimées après migration des usages. Le scheme mentionne line/column mais les déclare non implémentés ; ce constat ne justifie pas de développer une nouvelle fonction dans cet audit.

Utilitaires et catégories : interfaces et implémentations lues, entrées nil/bornes et ownership, DOM textCount et exclusion code/script/style, parsing des couleurs du computedStyle, création sans écrasement, JSON stream fermeture, escaping des tables HandleBars, lookup lignes/front matter/title, insertion/matching/listes/markers/header/indentation, domaines CFPreferences explicites, API privée zoom consommée, fichiers drag/data/clipping/UTI, processus brew/mainQueue/cycle, callbacks MathJax exposés, watches vnode FD/cancellation/restart tokens, extraction URL HTML/cache params/entity decoding, confinement fichier résolu et detection exécutables, répertoires/styles/themes/fallback bundled, fichiers temporaires privés, JSCore cleanup et listes historiques prune.

Défaut confirmé A2-D01 : sélection perdue lors d'indentation de lignes vides. Commit ec48d63, six contrats AppKit réels verts avec allers-retours indentation/désindentation. Aucune suppression legacy : maps et API zoom possèdent des consommateurs actifs. Les scénarios PDF/DOM, publication atomique et générations ont été confrontés aux tests frais de campagne 02 ; aucun succès historique de campagne 01 ne remplace ces exécutions.

Candidats non certifiés : lecture stdout brew après termination pourrait bloquer une sortie volumineuse mais l'unique consommateur utilise --prefix ; aucune correction sans scénario réaliste confirmé. Les gardes couleurs ne sont pas des entrées de CSS brute utilisateur : le consommateur lit computedStyle WebKit. Les API raw HTML/JS du preview sont intentionnelles ; une différence avec QuickLook CSP n'est pas à elle seule une faille ou duplication métier à supprimer.

Vérifications finales :1436 XCTest, zéro échec,49 tests ciblés natifs scripting/CLI,4 XCUITest, zéro échec ; Debug/Release arm64+x86_64 ; contrats sandbox préférences/assets. A2-D02 f5870f5 : MPDocument final de 5392 lignes entièrement relu, notification/rendu/save littéraux et état modifié/undo/redo/no-op/manuelle/fallback vérifiés sur vrai document/nibs/AppleEvents. Le dernier PDF natif compile les deux constantes JS extraites du source546d et l'injector902c ; deux NSPrintOperations, transfert interne puis resolved.pdf écrit sur disque et rouvert par initWithURL, destination page/point valide et pixels RGBA identiques aux originaux immuables capturés avant mutation ; DOM/CSSOM/session restaurés. Preuve campagne02-pdf-native.json, rapport ss0j95yq. Le probe antérieur u06tm06z vérifiait la sérialisation en mémoire/PNG encodés ; il ne certifiait pas la réouverture disque et est supersédé. Aucun champ de préparation n'est traité comme une exécution.

Seconde passe : validations de chemins résolus et génération du preview, callbacks différés après fermeture, publication export et identités PDF réexaminées ; CLI partagé uniformisé et migration échec préservant les données vérifiée. Sept tests natifs activation/reopen/documents et 320 demandes concurrentes interprocess complètent les tests des producteurs. La queue ne promet pas une livraison exactement une fois après crash entre drain et ouverture UI ; cette limite est explicite, sans la présenter comme une nouvelle garantie.
