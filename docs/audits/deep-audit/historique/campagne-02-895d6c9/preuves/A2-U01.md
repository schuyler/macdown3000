# A2-U01 — une mise à jour différée rétablit la géométrie après désactivation

Campagne 02, baseline `e5a5c237b92d172e953abf0680869ad0a5b4806f`, 7 octobre 2026.
Défaut confirmé et corrigé, priorité P2. Correction ciblée ; aucune refonte.

## Préconditions et résultat consommé

`MPEditorView.setScrollsPastEnd:YES` et `setString:` quand le mode est actif mettent
`updateContentGeometry` en file sur la vraie `NSOperationQueue.mainQueue`.
Le mode peut être désactivé avant leur exécution : le setter remet alors
`contentRect` à zéro, et son getter doit renvoyer `self.frame` tant que le mode
reste désactivé. C'est le contrat documenté du setter.

Avant correction, l'opération en attente ne recontrôle pas ce mode. Elle réécrit
`contentRect` à partir du layout, même après désactivation. Le getter public ne
renvoie donc plus la frame. `MPDocument.setupEditor:`, branche
`editorScrollsPastEnd` (autour de la ligne 3579 lors de la lecture), consomme ce
getter pour calculer et appliquer la frame. La protection conditionnelle dans
`didChangeText` n'annule pas les opérations déjà mises en file ; celle dans
`setFrameSize:` empêche l'ajout de hauteur, mais ne restaure pas le getter.

Invariant : une opération différée ne réactive pas un résultat de géométrie qui
appartient au mode désormais désactivé. Les opérations du mode actif continuent
à produire un `contentRect` mesuré, y compris après OFF puis ON.

## Correction

`MacDown/Code/View/MPEditorView.m` : retour immédiat au début de
`updateContentGeometry` si `scrollsPastEnd` est actuellement désactivé.
La branche synchrone et les deux entrées différées convergent sur cette garde.
L'intégralité de la version finale de ce fichier a été relue.

## Régression exécutée rouge puis vert

Le nouveau runner `MacDownTests/UI/test_editor_geometry.sh` compile les sources
réelles `MPEditorView`, `NSPasteboard+Types` et `FileURLInlining`. Son argument
optionnel permet d'utiliser une copie immuable de la source baseline sans
modifier l'arbre partagé. Compilation limitée à 60 secondes et exécutable à
30 secondes avec `subprocess.run(timeout=...)`; un blocage produit le code 124.

`EditorGeometryRegression.m` crée de vrais `NSTextView` et `NSLayoutManager`,
force le layout, puis consomme `contentRect` après les opérations de production.
La vérification dépend explicitement des opérations déjà en file : aucun délai
heuristique, aucun remplacement de la géométrie/main queue. Seule la frontière
NSUserDefaults est remplacée en mémoire avant de créer NSApp/vues, pour ne
muter aucun domaine réel. Aucun clipboard général ou Finder n'est utilisé.

Scénarios : activation puis désactivation avant exécution ; changement du texte
programmé avant désactivation ; désactivation suivie d'une réactivation positive.

```sh
git show e5a5c237b92d172e953abf0680869ad0a5b4806f:MacDown/Code/View/MPEditorView.m > /tmp/macdown-a2-ui/baseline-MPEditorView.m
MacDownTests/UI/test_editor_geometry.sh /tmp/macdown-a2-ui/baseline-MPEditorView.m
MacDownTests/UI/test_editor_geometry.sh
```

Résultat rouge : code 1, `FAIL disabled contentRect={{0, 0}, {38.67578125, 28}}
frame={{0, 0}, {300, 200}}`.
Résultat vert : code 0, `PASS deferred enable, text change, disable and re-enable geometry`.
Les 7 warnings existants de `FileURLInlining` (performSelector et UTType dépréciés)
sont consignés ; aucun warning masqué par le runner.

## Seconde passe et limites

La garde lit l'état au moment où l'opération s'exécute, plutôt que de capturer
l'état de sa programmation. Une réactivation laisse une ancienne opération
recalculer à partir du texte courant, ce qui reste conforme au contrat.
Tous les changements de géométrie AppKit considérés sont sur le thread principal ;
la correction ne prétend pas rendre AppKit utilisable depuis un worker.

Le test démontre le résultat public consommable et le layout réel, mais ne
construit pas un `MPDocument`/nib complet. Root doit rejouer le nouveau test sur
l'arbre final, puis les gates Xcode autorisées : bindings préférence, document,
scroll view et bascule utilisateur ON/OFF avec texte chargé et édité. Ces gates
n'ont pas été exécutées dans ce lot. La validation globale du fichier demeure
ouverte pour les autres parcours UI (paste/drop/substitutions).
