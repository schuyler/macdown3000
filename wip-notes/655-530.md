# #655 macOS 14 runner retirement / #530 pane width slack

## #655 Requirements (posted on issue #655)
1. (stated) No workflow depends on the macos-14 image, so CI and release workflows keep running after 2026-11-02. AC: nothing under .github/ names macos-14; a PR's checks run on the new image without being cancelled.
2. (inferred) The release build still works on the new image. AC: "Verify Release Build (Dry Run)" (archives through the same build-macdown action as release.yml) passes on the new image; the smoke-test workflow passes when dispatched.
3. (inferred) The test matrix keeps its shape: oldest supported image plus newest.

## #655 Design
Replace `macos-14` with `macos-15` in: release.yml (runs-on), staple-release.yml, build-release.yml, quicklook-versions.yml, test.yml matrix, smoke-test.yml matrix. macos-15 (arm64) is GitHub's current non-deprecated successor (runner-images README); default Xcode 16.4 (macos-14 defaulted to 15.4); project MACOSX_DEPLOYMENT_TARGET = 11.0. No other workflow changes. Also update the two `runs-on: macos-14` examples in plans/xcuitest.md? -> No: plans/ is a planning doc, not a workflow; out of scope.

## #530 Requirements (posted on issue #530)
1. (stated) Every Settings > Editor checkbox label shows in full in every shipped localization, even when text measures slightly wider at draw time than when the pane was sized. AC: in testEditorPaneCheckboxTitlesFitInEveryLocalization (MacDownTests/MPPreferencesViewControllerResizabilityTests.m), for every locale and checkbox, the title still fits its title rect without an extra line when measured 3% wider.
